# IFRC - 图片格式转换下载器

一个适用于 Tampermonkey 的图片格式转换脚本。
在网页图片上点击右键，即可将图片转换为指定格式后下载。

当前版本：`1.2.0`

## 功能

- 识别网页中的 `<img>` 图片和 CSS `background-image` 背景图片。
- 支持转换为：
  - PNG：无损，支持透明背景
  - JPG：兼容性好，文件体积通常较小
  - WebP：现代图片格式，体积较小
  - AVIF：压缩率高，是否可用取决于浏览器
  - BMP：无损但文件体积较大（脚本内置编码器，不依赖浏览器支持）
- JPG、WebP、AVIF 支持调整输出质量（60%–100%）。
- 自动检测浏览器能否编码某种格式，不支持的格式直接置灰并注明原因，不会让你点了才失败。
- 显示缩略图、原始格式和图片尺寸。
- 保留原文件名并替换扩展名；也可以直接用「下载原图」保存原始文件。
- 键盘操作：`1`–`5` 直接选格式，`Esc` 关闭菜单。
- 右键菜单跟随系统深色 / 浅色模式。
- 支持跨域读取图片（依赖 `GM_xmlhttpRequest`）。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 Tampermonkey 管理面板。
3. 点击“添加新脚本”。
4. 将 [ifrc-image-converter.user.js](./ifrc-image-converter.user.js) 的全部内容复制到编辑器中。
5. 保存脚本，快捷键通常为 Ctrl + S。
6. 刷新需要使用脚本的网页。

## 使用方法

1. 打开包含图片的网页。
2. 在图片上点击鼠标右键，弹出转换菜单。
3. 选择目标格式；JPG、WebP 或 AVIF 可先拖动质量滑块。
4. 转换完成后自动下载，菜单会显示文件大小。

### 保留网页原生右键菜单

按住 `Shift` 再右键即可跳过本脚本，使用浏览器或网站自带的菜单。

## 格式说明

| 格式 | 特点 | 透明背景 | 质量设置 | 实现方式 |
| --- | --- | --- | --- | --- |
| PNG | 无损，适合截图、图标和文字 | 支持 | 不需要 | Canvas 编码 |
| JPG | 兼容性最好，适合照片 | 不支持，透明区域填白 | 支持 | Canvas 编码 |
| WebP | 体积小，适合网页图片 | 支持 | 支持 | Canvas 编码 |
| AVIF | 压缩率高，追求更小体积 | 支持 | 支持 | Canvas 编码 |
| BMP | 无损、格式简单，但文件很大 | 不支持，透明区域填白 | 不需要 | 脚本自带编码器 |

AVIF 依赖浏览器的编码能力。菜单打开时会检测一次，若当前浏览器不支持，该按钮直接置灰。

## 已知限制

- 使用防盗链、登录态或临时签名地址的图片可能读取失败。
- 图片地址返回的不是图片数据时，转换会失败并提示原因。
- 仅通过 Canvas 绘制、分块加载或加密传输的图片无法识别。
- JPG 与 BMP 没有透明通道，透明区域会填成白色。
- 单张图片超过 100MP 会被拒绝（浏览器 Canvas 上限）；BMP 因为要逐像素写入，上限是 24MP。
- 脚本通过浏览器下载机制保存文件；如果浏览器拦截了自动下载，请允许当前网站下载文件。

## 常见问题

### 为什么 AVIF 按钮是灰的？

当前浏览器的 `canvas.toBlob` 不支持编码 AVIF。可以换用 WebP 或 PNG。

### 为什么某些图片无法转换？

常见原因是防盗链、需要登录、图片地址已过期，或服务器拒绝非页面上下文的请求。可以先在网页中直接打开图片确认可访问。

### 为什么下载的文件名不理想？

文件名取自图片 URL 的最后一段。使用随机 ID 或无扩展名接口的站点，可能得到随机字符串或 `image`。

## 开发

单文件用户脚本，无构建依赖。改动后可直接用 Node 检查语法：

    node --check ifrc-image-converter.user.js

## 安全与隐私

- 图片转换完全在浏览器本地完成。
- 不上传图片到任何第三方转换服务。
- 跨域读取的目标就是当前图片自身的 URL。
