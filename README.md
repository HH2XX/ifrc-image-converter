# IFRC - 图片格式转换下载器

一个适用于 Tampermonkey 的图片格式转换脚本。  
在网页图片上点击右键，即可将图片转换为指定格式后下载。

## 功能

- 识别网页中的 <img> 图片和 CSS background-image 背景图片。
- 支持将图片转换为：
  - PNG：无损，支持透明背景
  - JPG：兼容性好，文件体积通常较小
  - WebP：现代图片格式，体积较小
  - AVIF：压缩率高，是否可用取决于浏览器
  - BMP：无损但文件体积较大
- JPG、WebP、AVIF 支持调整输出质量。
- 显示图片缩略图、原始格式和图片尺寸。
- 自动保留原文件名，并替换为新的扩展名。
- 支持跨域读取部分图片。
- 支持深色模式。
- 支持按 Esc 关闭转换菜单。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 Tampermonkey 管理面板。
3. 点击“添加新脚本”。
4. 将 [ifrc-image-converter.user.js](./ifrc-image-converter.user.js) 的全部内容复制到编辑器中。
5. 保存脚本，快捷键通常为 Ctrl + S。
6. 刷新需要使用脚本的网页。

也可以直接打开 ifrc-image-converter.user.js，复制全部代码后粘贴到 Tampermonkey 的新脚本页面。

## 使用方法

1. 打开包含图片的网页。
2. 将鼠标移动到图片上。
3. 点击鼠标右键。
4. 在“图片格式转换”菜单中选择目标格式。
5. 对 JPG、WebP 或 AVIF，可以先拖动质量滑块。
6. 脚本转换完成后会自动下载文件。

如果右键菜单没有出现，请确认脚本已启用，并刷新网页。

## 格式说明

| 格式 | 特点 | 透明背景 | 质量设置 |
| --- | --- | --- | --- |
| PNG | 无损，适合截图、图标和文字 | 支持 | 不需要 |
| JPG | 兼容性最好，适合照片 | 不支持，透明区域会变成白色 | 支持 |
| WebP | 体积小，适合网页图片 | 支持 | 支持 |
| AVIF | 压缩率高，适合追求更小体积 | 支持 | 支持 |
| BMP | 无损，格式简单，但文件很大 | 不支持，透明区域会变成白色 | 不需要 |

AVIF 依赖浏览器的编码支持。如果选择 AVIF 后提示浏览器不支持，可以改用 WebP、PNG 或 JPG。

## 权限说明

脚本头部包含以下 Tampermonkey 权限：

    @grant  GM_xmlhttpRequest
    @connect *

这些权限用于读取不同域名上的图片，以便将跨域图片绘制到 Canvas 并重新编码。脚本只会在用户右键选择转换后读取当前图片地址，不会主动扫描或上传图片。

如果你不希望授予跨域请求权限，可以删除 @grant 和 @connect，但跨域图片的转换成功率会降低。

## 已知限制

- 某些网站使用防盗链、登录验证或临时签名地址，脚本可能无法读取图片。
- 图片地址如果返回的不是图片数据，转换会失败。
- 图片如果使用特殊加密、分块加载或仅通过 Canvas 绘制，可能无法直接识别。
- JPG 和 BMP 不支持透明通道，透明区域会使用白色填充。
- 超大图片会占用较多内存，转换过程可能需要几秒钟。
- 脚本通过浏览器下载机制保存文件；如果浏览器阻止自动下载，请允许当前网站下载多个文件。

## 常见问题

### 文件扩展名改了，但内容没有转换吗？

不会。脚本使用 Canvas 重新编码图片，并根据实际输出格式生成 Blob，不是简单修改文件名。

### 为什么 AVIF 转换失败？

AVIF 编码支持取决于浏览器版本。请更新浏览器，或者改用 WebP/PNG。

### 为什么某些图片无法转换？

常见原因是网站防盗链、图片需要登录、图片地址已过期，或者服务器拒绝跨域请求。可以尝试在网页中直接打开图片，确认图片本身可以正常访问后再转换。

### 为什么下载的图片文件名不理想？

脚本会从图片 URL 的最后一段获取文件名。如果网站使用随机 ID、无扩展名 URL 或动态接口，文件名可能会显示为随机字符串或 image。

## 开发

本项目是单文件 Tampermonkey 用户脚本，不需要构建工具或依赖安装。

修改 ifrc-image-converter.user.js 后：

1. 在 Tampermonkey 编辑器中替换脚本内容。
2. 保存脚本。
3. 刷新网页。
4. 在图片上右键测试。

提交前可以使用 Node.js 检查 JavaScript 语法：

    node --check ifrc-image-converter.user.js

## 安全与隐私

- 图片转换在浏览器本地完成。
- 脚本不会将图片上传到第三方转换服务。
- 跨域读取时，请求目标是当前图片自身的 URL。
- 使用第三方网站图片时，仍应遵守网站的版权、访问规则和服务条款。
